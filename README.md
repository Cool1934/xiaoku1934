# Lumina · 视频社区网站

一个开箱即用的视频网站，支持**邮箱登录**、**用户上传视频**、**在线播放**，UI 精美且**同时适配手机和电脑**（响应式设计）。

## ✨ 功能

- 🎬 **浏览视频**：卡片网格 + 悬停动效，自适应列数
- ▶️ **在线播放**：播放页 + 相关推荐侧栏
- 📱💻 **全端适配**：手机（单列 + 底部导航）/ 平板 / 电脑（多列 + 侧栏）
- ✉️ **邮箱登录**：输入邮箱 → 验证码两步登录（注册即登录，无需密码）
- ⬆️ **上传视频**：登录后才能上传，拖拽/选择文件，带进度条
- ❤️ **点赞 / 分享**、搜索、观看计数
- 💾 **本地持久化**：数据存浏览器 localStorage，刷新不丢失

## 🚀 运行方式

这是一个纯静态站点，**无需构建、无需后端**，双击即可运行：

### 方式一：直接打开
双击 `index.html` 即可在浏览器打开。

### 方式二：本地服务器（推荐，上传功能更稳）
```bash
# Python
python3 -m http.server 8080

# 或 Node
npx serve .
```
然后访问 `http://localhost:8080`

> ⚠️ 首次打开时演示视频从 Google 公共 CDN 加载，需联网。上传的视频保存在本地浏览器中。

## 🔑 邮箱登录说明

当前为**前端演示版本**：
- 输入任意有效邮箱，点击"发送验证码"
- 会弹出提示框显示验证码（模拟邮件），输入即可登录
- 接入真实后端时，把 `LoginModal` 里的验证码逻辑替换为邮件发送 API 即可

## 🛠 二次开发（接入真实后端）

如需真实上传/登录，建议：
1. 用 `src/` 下的 React 源码 + Vite 构建（`npm install && npm run build`）
2. 后端：Node.js/Express + PostgreSQL
3. 视频存储：阿里云 OSS / AWS S3 + FFmpeg 转码为 HLS
4. 认证：NextAuth / JWT，邮箱验证码通过 SMTP 发送

## 🎨 技术栈

React 18 + Babel Standalone（CDN）+ 纯 CSS（深色主题、毛玻璃、渐变、响应式）
